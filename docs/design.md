# 瞬搜 QuickSwitch — 第一版实现规格

2026-11-10。依据用户确认的方案 A、Command+E 和「已有标签＋浏览历史匹配＋回车搜索」，以及本机 Arc 实测。

## 用户行为

- Mac 默认 ⌘E 打开/关闭临时面板；原生 ⌘T 保留。安装后检测快捷键是否成功注册，提供 Chrome 快捷键设置入口。⌘E 与原生查找选中文字存在冲突，实机验收前不能保证该组合触发。
- 普通 HTTP/HTTPS 网页上居中显示面板，输入框自动聚焦，页面背景变暗。Esc、点击遮罩关闭并恢复原焦点。↑↓选择，Enter 执行，支持中文输入法组合输入。
- 空输入展示最多 8 条最近使用/访问页面，以最近时间排序，排除当前标签；同一 URL 仅展示一条，优先保留已有标签。无历史时显示空状态。
- 输入后匹配标题、域名、完整网址，大小写不敏感，支持多个空格分隔关键词。强匹配可排在「搜索输入文字」之前，弱匹配在其后；结果综合相关度、最近访问、访问频次，最多 12 条，搜索项始终保留。
- 可识别 HTTP/HTTPS、无协议域名、localhost/端口、IP。省略协议补 HTTPS，localhost/回环 IP 补 HTTP。不执行 javascript/data/file 等非网页协议；含账号密码的 URL 拒绝，防止错误当搜索发送。
- 网址前缀强匹配已知主页时补全域名并选中后缀；不请求在线搜索词联想。
- 既有标签标注「切换到标签」，历史标注「历史记录」，输入网址标注「访问网址」，搜索标注「默认搜索引擎」。
- 点击/Enter 访问前重新查询标签。规范化完整 URL 一致则激活原标签并聚焦所属窗口，不刷新页面、不创建重复标签。保留路径、查询参数、hash、协议含义；同域名不同页面分别处理。
- 如无匹配标签，新建标签访问目标网址。搜索通过 chrome.search.query 使用用户的默认引擎，新标签展示结果，不覆盖当前页面。
- 支持同一 Chrome 用户配置中的多个普通窗口。第一版禁用无痕，避免普通历史混入无痕。不能跨 Chrome 配置文件或切换 Arc 标签。
- Chrome 内部页面、商店等注入受限页面无法注入框架，改为在当前窗口中央打开 560×420 的小面板（`popup.html?context=<tabId>`），高度贴合内容，失焦自动关闭。扩展不声明 `action`，因此没有工具栏图标，快捷键设置页也不会出现「激活该扩展程序」这一行。

## 数据、权限和架构

- Manifest V3，最低 Chrome 127。无构建依赖、无远程脚本、无后端。
- 权限 tabs/history/search/activeTab/scripting/favicon/storage。只按用户触发临时注入，不申请所有站点的常驻 host 权限；favicon 使用 Chrome 扩展内置接口，不接第三方图标服务。storage.session 只保存随机面板令牌，不保存查询或历史。
- core.mjs：URL 识别、去重、评分、候选构造。service.mjs：Chrome API 检索与执行。worker.mjs：快捷键、注入、消息入口。palette.js：可复用的面板 UI。content.js 只挂载独立扩展来源 iframe；overlay.js/popup.js 负责两种面板宿主；frame-sessions.mjs 验证标签绑定的面板令牌。
- 网页 UI 放在独立扩展来源 iframe 中，避免输入事件经过宿主网页；内部再使用 closed Shadow DOM 隔离样式，使用 DOM textContent 呈现标题和网址。消息仅接收本扩展，iframe 查询需携带当前标签令牌，创建和撤销按标签串行处理；仅允许 HTTP/HTTPS 导航。
- 浏览历史按需查询，空输入最多读取最近 500 项；输入时另查历史关键词并在有界候选内评分。并非全文索引全部历史。无查询/历史副本存储，无日志记录用户查询/历史，无遥测；搜索确认后才交给默认搜索引擎。
- 异步结果以请求序号防止旧结果覆盖，输入法 Enter 不触发跳转；执行期间禁重复提交。失败在面板提示，保留输入供重试。

## 验收

1. 普通网页 ⌘E 出现居中面板且聚焦，⌘T 仍正常新建标签。
2. 文字回车进入当前默认引擎的搜索结果。
3. 域名、完整 URL、localhost 均按规格识别。
4. 已有相同 URL 激活原标签，包括其他窗口，不增加标签、不刷新。
5. 同域名不同路径不错误切换；历史条目可打开。
6. ↑↓/Enter/Esc/点击关闭/中文输入法正确工作。
7. 受限页面出现备用扩展弹窗；无权限或 API 失败有明确反馈。
8. URL 解析和排序单元测试、API 适配测试通过；界面预览验证和真实 Chrome 验收分别记录，不能将模拟测试表述为实机验收。

Arc 精确排名权重不是公开可调用能力，本版是可观察交互的近似实现；不包含在线联想、书签检索、Arc 管理命令或 AI 功能。
