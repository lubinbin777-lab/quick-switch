# 瞬搜 · QuickSwitch

一个参考 Arc Command Bar 交互的 Chrome 扩展。第一版支持已有标签、浏览历史匹配、网址跳转和默认搜索引擎搜索。

**当前状态：v1.1.0，已在本机 Chrome 中日常使用。31 项 Node 测试、11 项浏览器交互测试、独立 Chrome 配置下的 9 项端到端验收（8 项通过，原生 ⌘T 待人工按键）均已完成，记录见 [docs/e2e-acceptance-2026-11-10.md](docs/e2e-acceptance-2026-11-10.md)。**

## 安装

需要 Chrome 127 或更新版本。

本扩展**没有上架 Chrome 网上应用店**（个人自用，不打算付一次性 5 美元注册费），通过 GitHub Releases 分发，安装方式是「加载已解压的扩展程序」。

1. 到 [Releases](../../releases/latest) 下载 `quick-switch-extension.zip`；也可以直接 `git clone` 本仓库，用仓库里的 `extension/` 目录。
2. 解压到一个固定位置（例如 `~/.quick-switch/`）。以后升级覆盖同一目录，再在 Chrome 里点一次「重新加载」即可。
3. 地址栏打开 `chrome://extensions/` → 右上角开启 **开发者模式** → 点 **加载已解压的扩展程序** → 选择解压出来的 `extension` 文件夹（里面直接有 `manifest.json`，不要选上一级目录）。
4. 回到普通网页按 **⌘E**。

> 开发者模式会常驻一条黄色提示，这是加载未上架扩展的固有代价。
> 扩展不声明工具栏按钮，**装完工具栏不会有图标**；如果 ⌘E 被其他扩展占用，你会没有任何入口。第一次安装后建议先去 `chrome://extensions/shortcuts` 确认快捷键已绑定。

## 快捷键

- Mac 默认：**⌘E**。
- Windows/Linux 备用默认：Ctrl+Shift+E，尚未做对应平台实测。
- 原生 **⌘T** 保留。
- ↑↓ 选择结果，Enter 打开，Esc 或点击面板外关闭。
- 快捷键被其他扩展占用、或未成功注册时：打开 `chrome://extensions/shortcuts`，找到「瞬搜」→「打开 / 关闭瞬搜面板」设置快捷键；未绑定时面板会在结果下方给出提示。
- ⌘E 与 Chrome 的「查找选中文字」有冲突，因此以实机测试结果为准；如果浏览器优先处理原生功能，在快捷键设置里改键即可。

## 检索规则

- 空输入显示最近使用/访问的页面，默认最多 8 条。
- 输入后匹配标题、域名、网址，支持中文和空格分隔的多关键词，最多显示 12 条。
- 强匹配页面可排在搜索项前；始终保留原文搜索选项。可按 ↓ 选择「默认搜索引擎」进行搜索。
- 网址前缀匹配已知主页时补全域名，后缀自动选中；继续输入可覆盖。
- 同一完整 URL 的历史和已有标签合并；选择已有页面会切换原标签并聚焦其窗口，不刷新、不重复新建。
- **相同域名不代表相同页面**。路径、查询参数、hash、HTTP/HTTPS 差异保留，避免误跳转。
- 没有打开的网页会在新标签中打开。普通搜索使用 Chrome 当前默认搜索引擎。
- 支持域名、完整 HTTP/HTTPS、localhost 和 IP/端口；拒绝带账号密码的 URL 与非网页协议。

## 权限与数据

| 权限 | 用途 |
|---|---|
| tabs | 检索标签标题/网址、切换已有标签和窗口 |
| history | 查询浏览历史候选 |
| search | 使用 Chrome 当前默认搜索引擎 |
| activeTab + scripting | 用户按快捷键时，在当前页挂载面板 |
| favicon | 使用 Chrome 的网站图标接口 |
| storage | 在浏览器会话内保存随机面板令牌，防止未授权框架请求数据 |

没有远程脚本、后端、遥测或在线搜索词联想；不保存查询和浏览历史副本。检索在本机进行，只有确认搜索/访问后才导航到默认搜索引擎或目标网站。输入框运行在独立扩展来源框架中，避免键盘事件被当前网页的监听器接收。

## 已知边界

- 扩展不声明工具栏按钮，因此**没有工具栏图标**，入口只有快捷键；这也是快捷键页不出现「激活该扩展程序」的原因。
- Chrome 设置页、新标签页、Chrome 网上应用店及不允许插入框架的页面无法显示页面中央浮层，会改为在当前窗口中央打开一个小面板（560×420，高度贴合内容），失去焦点即自动关闭。框架加载失败会在约 6 秒后切到同一个备用面板（首次打开时 service worker 冷启动可能较慢，超时留有余量）。
- 只处理当前 Chrome 配置内的普通窗口，不支持无痕、跨配置文件或 Arc 中的标签。
- 历史候选按需有界查询，不是对全部历史建立完整全文索引。
- 排序是根据 Arc 实测行为实现的近似规则，不是 Arc 内部算法的精确复制。
- 更新扩展后，已打开网页里的旧注入脚本可能需要刷新页面。
- 未上架 Chrome 网上应用店，通过 GitHub Releases 分发；升级需要替换目录并在 `chrome://extensions` 点一次「重新加载」。

## 测试与源码

无需安装依赖，在项目根目录运行：

```sh
npm test        # 31 个 Node 测试
npm run check   # manifest、语法与资源路径
npm run e2e     # 端到端验收：真实 Chrome 内核跑 9 项清单并截图
```

浏览器交互测试：启动本机静态服务，打开 `tests/browser.html`。它运行实际面板代码，但 Chrome API 使用人工测试数据。

`tests/isolation.html` 是独立来源键盘隔离验证页，测试地址使用本机端口 8766 和 localhost/127.0.0.1 两个来源。

- `extension/`：可以加载到 Chrome 的全部插件文件。
- `tests/`：核心、API 边界、会话并发与浏览器交互测试。
- `docs/design.md`：行为与实现规格。
- `docs/validation.md`：已经验证和仍待实机验证的项目。
- `docs/e2e-acceptance-2026-11-10.md`：端到端验收记录与截图。
- `scripts/e2e-acceptance.mjs`：可复现的端到端验收脚本（产物写 `docs/e2e/`）。

## 安装后的验收顺序

1. 在普通网页按 ⌘E，确认出现浮层并可直接输入；按 Esc 关闭。
2. 输入 `example.com` 回车，确认新标签打开该网址。
3. 再输入相同网址，确认切换原标签而不新增。
4. 输入一个已打开网页标题，选择「切换到标签」，确认不刷新。
5. 将目标标签移动到另一个普通窗口，重复切换测试。
6. 输入普通文字，选择搜索项，确认使用当前默认引擎。
7. 用中文输入法输入并确认候选，确认选词 Enter 不提前跳转。
8. 在 Chrome 新标签页按快捷键，确认备用扩展弹窗可用。
9. 按 ⌘T，确认 Chrome 原生新建标签行为保留。
